---
name: code-review
description: 审查代码和 Git 变更，查找有证据、可复现的问题。适用于代码审查；需要直接修改代码时按用户任务执行。
---

先确认审查范围：用户指定的文件、提交或当前 Git 变更。没有指定范围时查看当前变更，不扩展成无边界的全仓库检查。

阅读修改及其调用方，关注行为错误、边界条件、兼容性和数据丢失。结合项目约定判断，不把个人风格偏好当成缺陷。

每个问题说明触发条件、实际影响和文件位置。可以用小范围测试验证，但不要为审查擅自修改实现。区分已验证的问题和仍待确认的推测。

先报告影响最大的问题。如果未发现问题，直接说明，并列出真正影响结论的验证限制。
