# 数据分析

1. 明确分析问题、数据范围、单位、时间区间和交付形式；对答案有影响的缺失条件才询问。
2. 检查输入文件格式、字段类型、缺失值、重复记录、样本量与明显异常。优先读取少量样本和结构，再处理完整数据。
3. 保留原始文件。将清洗规则和排除条件显式记录，禁止为了得到预期结论选择性删样本。
4. 使用当前环境实际可用的 Python/命令工具；先检查库和格式支持，缺少 Excel、绘图库等依赖时说明，不声称存在专属表格编辑器。
5. 区分描述统计、相关性与因果推断。比较分组时核对分母、单位、基线和不确定性；不凭小样本断言显著性。
6. 对重要数值用独立汇总或简单不变量交叉核对；图表标清坐标、单位、样本范围和处理方式。
7. 产物保存到用户指定位置或当前工作目录，用相对路径记录数据来源和复现步骤。不要把数据或 Key 上传外部服务，除非得到授权。
8. 最终给出结果、方法、局限、产物位置和复现命令；区分运行得到的数字与推测，数据不可读时不编造结果。
