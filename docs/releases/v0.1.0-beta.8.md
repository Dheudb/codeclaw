# CodeClaw v0.1.0-beta.8

MCP 工具复用现有按需发现机制。连接后不再将全部工具的详细参数塞进每次模型请求；CLI 与桌面共用注册入口，通过 `tool_search_tool` 搜索并加载需要的工具。加载只改变可见性，执行仍遵循原有授权、显式询问/拒绝和 Plan 限制。

成功重连替换工具连接并保留仍存在工具的加载状态；停用同时移除活动和潜在目录中的条目。MCP 工具与内置活动/潜在工具名称冲突时，注册明确拒绝，避免部分注册或覆盖。子代理原有工具与服务范围限制继续适用。

下载 `CodeClaw-v0.1.0-beta.8-windows-x64.zip`，完整解压后运行 `CodeClaw.exe`。本地继续更新同一原 EXE 的资源，构建 `20261027-225036`，保留回滚资源。
