# Xuloom v0.1.0-beta.18

Windows x64 便携版，完整解压后运行 `Xuloom.exe`。本地沿用原安装路径更新。

本版根据 Codex、Pi、DSH 的公开源码及 Claude Code 官方资料继续加固通用执行基座：

- 文件写入、编辑和 Notebook 使用原子提交，失败保留原文件；首次创建不覆盖竞争写入，修改前检查本 agent 观察版本。
- 父子代理共享真实路径写队列，读证据分别保存；复用现有 OS 锁处理不同进程的文件修改竞争，取消正确释放并记录状态。
- Notebook 完整读改写进入队列，避免并行编辑互相覆盖。
- REPL 取消清理自有进程；命令退出后有界排空输出，管道未关闭时明确显示输出不完整。
- 网页长文本复用完整结果归档；二进制、过大响应、限流、超时与连接故障明确区分。
- Skill 设置复用原子保存；移除无用计划回写和无关写文件提示限制，没有新增全局提示词、运行时依赖或另一套调度器。

参考提交、测试证据和能力边界见 [源码对照与修复记录](../framework-source-comparison-2026-10-30.md)。本版不代表完成了真实远端长任务或 macOS/Linux 成品验收，也不宣称所有框架缺陷已排除。

不包含私人 Taiyi Skill、个人配置、密钥、历史或工作文件。
