# CodeClaw v0.1.0-beta.3

通用 Agent 框架与会话可靠性改造。普通问答直接回答；科研、写作、数据分析及编程通过同一套 Skill、原生子代理与 MCP 扩展机制使用。

## Windows 下载与使用

下载 `CodeClaw-v0.1.0-beta.3-windows-x64.zip`，完整解压后运行 `CodeClaw.exe`。Python 与 MCP 客户端依赖已随包提供。配置自己的模型连接即可使用；第三方 MCP 服务可能另有运行环境要求。

本地维护继续更新原启动路径的资源，EXE 不替换。更新前正常退出应用；旧资源保留用于回滚。个人会话、模型配置和外部 Skills 存放在用户目录，不放进程序包。

## 主要变化

- 默认提示词、内置子代理与记忆领域中立；去掉默认 Git 探测、按文件数量触发代码检查及自动提交建议。编程规则由新增的可选 `code-development` Skill 提供，并携带原生编程角色定义。
- CLI、桌面及程序接口统一加载选中的 Skill。长指令和结果保留完整存档；外部资料不能自行取得授权。
- 会话使用跨进程生命周期独占锁和检查点版本校验。其他入口可查看历史，但不能同时执行；进程退出后由操作系统释放锁，旧状态不能覆盖新版本。
- 会话新建、移动、复制和删除由持锁的同一执行器完成。完整结果先复制，再发布检查点；中断后核对哈希并恢复内部提交，用户文件留在原工作目录。侧栏索引按字段合并，迟到的草稿保存不复活已移动或删除的记录。
- `QueryEngine.agents` 提供结构化启动、等待、结果、取消和继续接口；稳定请求身份复用已有原生记录，不让模型转抄的 ID 或“完成”文字决定真实状态。
- 上下文压缩保留目标、约束、证据及工具状态。完整历史先存档，摘要失败保留原历史，不盲目重放不确定操作。
- Git 差异作为可选面板；保留文件树、预览、附件、运行过程、会话拖拽及面板宽度调整。

## 验证与边界

Python 3.12：209 项，208 通过、1 跳过；Python 3.9：209 项，204 通过、5 跳过。另有 Windows 更新器中途失败、回滚及重试专项通过。桌面逻辑 46/46；本地跨领域受控用例 6/6。真实进程中断、索引竞争、桥接退出及隐藏 Electron 测试的范围见 `docs/generic-validation-2026-10-27.md`。

本轮按用户选择只做本地验收，不调用远端模型；A1.5 排除。用例中的模型决策为确定性替身，不能据此宣称真实模型的研究质量、所有供应商兼容或小时级无人值守运行已经可靠。

当前“工作区隔离”是 Git worktree 或目录副本，不是进程、网络或宿主文件的操作系统安全沙箱。Linux/macOS 成品和系统级强隔离仍是独立里程碑。旧版应用不遵守新会话锁协议，升级前应关闭旧写者。

本包只包含 4 个公开内置 Skills。私人 Taiyi Skill、API 密钥、模型配置、聊天记录和个人工作区不进入源码或程序包。
