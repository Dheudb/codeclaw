# CodeClaw v0.1.0-beta.2

本版修复执行结果、持久化、权限和中断恢复的可靠性问题。桌面和 CLI 共用统一的结构化执行回执。

## 下载与启动

1. 下载 Assets 中的 `CodeClaw-v0.1.0-beta.2-windows-x64.zip`。
2. 完整解压，运行 `CodeClaw-win32-x64/CodeClaw.exe`。
3. 在“设置与模型”配置自己的 API 或本地模型服务。

包内包含 Python 和 MCP 依赖。请保留完整目录，单独复制 EXE 无法运行。
`Source code` 为源码；`SHA256SUMS.txt` 用于核对下载完整性。

## 修复内容

- 预算耗尽、输出中断、API 错误、取消和保存失败使用明确的结束原因；不再从回答文字推断任务完成。
- 子代理初始记录、最终结果和注册记录保存失败时，不能返回已完成；回执由代码绑定会话、代理和用户消息。
- Plan 禁止任意 REPL、命令和 MCP 执行；显式拒绝、询问规则在完全访问下仍生效。
- MCP 长文本、多模态块和结构化结果完整保留，复用统一存档和文件分页；保存失败明确报错。
- 工具执行前保存意图，完成后保存结果再通知界面；崩溃后复用已保存结果，不自动重放副作用不确定的操作。
- 修复取消通知重复、父任务退出清理和并发容量回收；当前轮超过 12 项工具回执也完整保留。
- Windows 短暂共享锁采用有限重试；持续存储错误仍明确失败并保留旧检查点。
- 对话身份介绍不自动注入或披露配置中的模型路由信息；模型设置仍由用户本地管理。

## 隐私与边界

发布包仅含 code-review、debug-issue、web-research 三个公开内置 Skill，不包含私人 Taiyi Skill、用户配置、API Key、聊天记录或个人工作区。私人和自定义 Skill 仍可在本地独立安装。

目前仅发布 Windows x64 便携测试版，尚无 macOS/Linux 成品、签名安装器或应用内自动更新。第三方 MCP 服务可能有额外运行环境要求。更新前关闭 CodeClaw，并保留旧程序包用于回退；不要删除个人数据目录。
