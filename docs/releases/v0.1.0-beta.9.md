# CodeClaw v0.1.0-beta.9

新增目标模式、正式非交互 CLI 和定时唤醒，复用现有引擎、会话、权限、子代理与恢复记录。没有增加第二套执行引擎或领域 Job 状态。

- **目标模式**：桌面右侧“目标”面板及 `codeclaw goal` 保存目标、验收条件和预算。支持安全续跑、暂停/恢复、取消、明确阻塞和防空转；主模型、原生 worker、摘要及记忆共享输出预算。文字条件等待人工/宿主验收，模型自称完成不直接通过。
- **非交互 CLI**：`codeclaw exec "任务" --json` 或 UTF-8 stdin 输入；输出 JSONL 事件与单一最终回执，收尾后自动退出。退出码明确区分失败、占用、存储失败、预算耗尽和缺少批准/输入。不会读取交互答案或自行授权。
- **定时唤醒**：桌面和 `codeclaw schedule` 创建延迟/固定间隔消息，投递到原会话，忙碌时排队。空闲不请求模型，错过多个周期合并一次；持久化投递身份防重复，执行中断不自动重放。

下载 `CodeClaw-v0.1.0-beta.9-windows-x64.zip`，完整解压后运行 `CodeClaw.exe`。本地继续更新原 EXE 的资源，构建 `20261028-113137`，保留回滚。便携包自带 Python 也支持 `-I -m codeclaw exec ...`。

用法、程序接口和退出码见 [目标与调度](https://github.com/Dheudb/xuloom/blob/v0.1.0-beta.9/docs/goals-and-schedules.md)。定时消息需要桌面打开或 `schedule serve` 运行；不安装隐藏开机服务，关机期间不执行。重复为固定秒数间隔，不是日历 Cron。金额预算和精确账单上限不在输出 Token 预算的保证范围内。

本地全量回归及原 EXE 验证记录见 [2026-10-28 验证](https://github.com/Dheudb/xuloom/blob/v0.1.0-beta.9/docs/task-modes-validation-2026-10-28.md)。仅使用本机协议模型替身；真实模型小时级验收仍未执行。系统级沙箱和 Linux/macOS 成品仍是独立里程碑。私人 Taiyi Skill 未修改、未上传、未打包；配置、密钥、历史和个人工作区不进入公开包。手动 CI 策略保留。
