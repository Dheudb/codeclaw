# CodeClaw v0.1.0-beta.1

首个公开 Windows x64 便携测试版：桌面 App 和 CLI 共用 Python 智能体引擎。

## 下载与启动

1. 下载 Assets 中的 `CodeClaw-v0.1.0-beta.1-windows-x64.zip`。
2. 完整解压，运行 `CodeClaw-win32-x64/CodeClaw.exe`。
3. 在“设置与模型”添加 API 协议、地址、模型 ID 和 Key，随后新建会话。

包内包含 Python 和 MCP 依赖，无需另外安装 Python、Node.js 或选择解释器。
请保留 `resources` 等完整目录；单独复制 EXE 无法运行。
`Source code` 是源码，不是 Windows 成品。`SHA256SUMS.txt` 用于核对下载完整性。

## 本版内容

- 独立会话分配专属工作目录；会话历史集中保存，项目目录用于代码和能力配置。
- API 支持多个连接、每个连接共用 Key 的模型列表、模型切换，以及删除连接和模型配置。
- Skills 按目录发现、输入 `$` 选择、按需加载；外部技能包可携带代理定义和 MCP 配置。
- 主代理和子代理支持工具审批、并行委派与任务管理；总结前等待已启动的子代理结束。
- 工具调用兼容 DSML，参数错误有次数受限的修正；保留已完成操作，避免静默重复执行。
- OpenAI 兼容流按结束标记收尾，检测无进展，保留断流的部分回答；显示接收阶段和首字耗时。
- 历史侧栏与右侧面板可调宽度，修复对话滚动；会话归档恢复和删除保留明确状态。
- 文件和图片附件、工作区文件浏览、文件修改统计、差异查看及 HTML 预览。
- 内置 code-review、debug-issue、web-research 三个公开技能。

发布包不包含用户 API Key、聊天记录、个人工作区或私人技能。

## 当前边界

- 目前仅发布 Windows x64 便携包，尚无 macOS/Linux 成品、签名安装器或应用内自动更新。
- 模型需自行提供 API；本地模型需已有推理服务。不同网关的工具调用和多模态兼容性需要单独验证。
- 第三方 MCP 服务可能有独立的 Node.js、uv、API Key 等要求。
- CLI 与桌面可以恢复同一份会话；同一会话请避免并发写入。

后续版本仍在完善，建议先在测试项目中使用。
