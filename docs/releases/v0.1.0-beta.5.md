# CodeClaw v0.1.0-beta.5

修复旧版独立会话从共享目录升级时，先创建目录和复制文件、后检查会话占用的问题。升级现在复用持有会话锁的存储执行器，先保存提交意图，再复制产物、提交历史和索引。占用时不创建新工作目录；中断后从现有存储记录恢复，原工作文件保留。

旧会话引用的二进制及大文件按块复制并校验完整哈希，失败不发布不完整文件，恢复不覆盖用户修改。缺失源文件会明确报错。私人 Skill 仅保留外部目录引用，不复制进新工作区或 EXE。已完成迁移但丢失界面回复时，重启根据检查点恢复活动会话和打开会话的目录关联，避免生成重复工作目录。

下载 `CodeClaw-v0.1.0-beta.5-windows-x64.zip`，完整解压后运行 `CodeClaw.exe`。本地仍更新原 EXE 的资源，构建 `20261027-205301`，保留上一版资源用于回滚。

本轮不调用远端模型。真实模型小时级任务、跨平台成品、系统级安全隔离和多实例界面偏好合并仍需独立验收。私人 Taiyi Skill、密钥、配置、聊天记录和个人工作区不进入源码或程序包，公开包仍只含 4 个内置 Skills。手动 CI 策略不变。
