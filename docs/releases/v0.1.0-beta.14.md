# Xuloom v0.1.0-beta.14

Windows x64 便携版。下载 Release 中的 ZIP，完整解压后运行 `Xuloom.exe`；GitHub 自动生成的 Source code 是源码，不是桌面程序。

本次更新：

- 每个 Markdown 代码块右上角增加“复制代码”，保留中文、缩进和换行，不带 Markdown 围栏或工具栏文字。
- 回复底部显示“复制回复”，便于复制整条回答；用户提示词继续支持复制和手动选择文字。
- 复制成功显示“已复制”；代码复制失败会提示重试或手动复制。
- 框架文档同步当前无限默认、显式宿主限制和 FIFO 排队规则，补充容量字段及等待、恢复语义。历史验收记录明确标注旧配额。

验证：

- TypeScript 检查及生产构建通过。
- 原 EXE 的消息操作测试通过：整条回复、提示词及代码复制，中文与缩进，键盘操作，剪贴板失败重试，手动选择文字、会话分支及重启恢复。
- 网页链接回归测试通过；未调用远端模型。
- 本次未重新运行 Python 全量测试；后端执行逻辑没有修改。

使用与隐私：

- 包含 Python、MCP SDK 和九个公开内置技能；模型 API 与 Key 由使用者自行配置。
- 不包含私人 Taiyi Skill、用户密钥、个人接口配置、聊天记录或工作目录。
- 本版为 Windows x64 Beta；完整解压后使用，`SHA256SUMS.txt` 可用于校验下载包。
