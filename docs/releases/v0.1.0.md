# Xuloom v0.1.0

发行名称统一为 `v0.1.0`，不再使用 beta 后缀，桌面品牌区也移除了“预览”标记。版本命名不改变模型兼容性与验证范围。

本版包含最新的框架与界面修改：模型派发默认后台运行，子代理角色由实际注册定义生成枚举，并在执行前校验；Markdown 回复支持真实图片展示与放大，无效、缺失和加载失败的图片不生成提示或空占位。文件阅读、模型思考控制、MCP、Skills、子代理、目标与会话能力继续复用现有引擎。

## 下载与启动

下载 `Xuloom-v0.1.0-windows-x64.zip`，完整解压，运行其中的 `Xuloom-win32-x64/Xuloom.exe`。请保留同目录的资源文件。包内自带 Python 与 MCP SDK，模型地址、模型 ID 和 Key 由使用者在设置中填写。

发行包只包含公开的九项内置 Skill，不包含私人 Taiyi Skill、模型凭据、聊天记录或工作区产物。校验文件为 `SHA256SUMS.txt`，包内 `RELEASE.json` 记录源码提交与构建号。

## 本次验证范围

- 版本调整后的 TypeScript/Vite 构建、52 项桌面逻辑测试、Markdown 图片端到端测试通过。
- 发行资源覆盖测试通过，确认只替换 ZIP 中的资源映射，保留原生 EXE/Python 运行时，不改动正在运行的安装。
- 功能修复的详细记录见 [执行过程与图片回看](../tool-transcript-2026-10-30.md) 和 [子代理校准](../ultra-delegation-2026-10-30.md)。
- 测试使用隔离配置、本地确定性接口；本次没有调用用户远端模型。真实模型自主委派频率和长任务、macOS/Linux 桌面发行包仍需各自验收。当前提供 Windows x64 桌面程序，Linux/macOS 可使用源码 CLI。
