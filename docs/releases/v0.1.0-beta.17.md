# Xuloom v0.1.0-beta.17

Windows x64 便携版。完整解压 ZIP 后运行 `Xuloom.exe`。

本版修复框架排查发现的工具回执与 Windows 执行问题：

- 修复修改记录器漏导入 `os`，以及文件已写入却因辅助记录异常而误报失败的问题。辅助异常会单独显示警告，不能据此重复写入。
- 明确 Windows Shell 是 cmd，采用会话工作目录，改进本地中文输出解码；推荐 `command_tool` 的结构化参数和 stdin。
- 旧 Shell 长输出复用完整结果归档，不再提前丢掉中间内容；加强自有进程树的取消、超时和启动失败清理。
- 修复命令输出上限、磁盘失败及初始/最终回执写盘失败的处理，避免假完成、管道等待或残留运行任务。
- 修复 Notebook 错误识别、命令失败状态识别，以及工作区路由文字破坏控制 JSON 的问题。
- 工具执行后的内部异常明确提示可能已有副作用；新增未定义变量检查和生产上下文故障回归。

完整范围、测试证据和未验证边界见 [框架排查记录](../framework-audit-2026-10-30.md)。仅做本地协议及故障测试，未新增真实远端模型长任务、Linux 或 macOS 成品验收。

不包含私人 Taiyi Skill、个人接口配置、密钥、聊天记录或工作目录。
