# Xuloom v0.1.0-beta.12

目标模式现在从输入框“＋ → 目标”选择，底部显示小目标图标；悬停或键盘聚焦时显示 ×，点击取消模式并保留草稿。直接输入目标并发送，不再要求先填写目标表单。

持续目标在输入框上方显示内容、累计执行时间、暂停／恢复、取消和详情入口。详细验收与预算仍可通过目标面板管理。等待用户验收不再显示为执行错误；暂停与取消保留已收到的结果。

修复目标、执行隔离窗口因遮罩样式缺失而挤入主布局的问题。模型选择器按当前名称占宽，选中 Sage-A1.5 等短名称时不再保留最长候选项的宽度，发送按钮保持靠右。

发布验证：TypeScript/Vite 构建通过，桌面逻辑测试 48/48、Python 桌面桥接测试 16/16 通过；更新后的原 Windows EXE 通过输入框端到端测试，覆盖目标选择及取消、发送与执行、暂停恢复、重新加载后的状态、详情窗口布局及短模型名称宽度。此前功能验收还覆盖目标引擎 13 项测试、目标与定时唤醒端到端测试及队列／系统隔离端到端测试。

所有模型测试均使用本机协议替身，没有调用远端模型。这不是完整跨平台或真实长任务验收。原有 Windows 系统隔离的适用范围保持不变。

发行包仅包含公开的内置技能；私人 Taiyi Skill、API 配置、密钥、聊天记录及个人工作区不上传或打包。GitHub Actions 继续仅允许手动触发。
