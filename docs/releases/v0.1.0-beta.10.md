# Xuloom v0.1.0-beta.10

项目由 CodeClaw 更名为 **Xuloom（序织）**，GitHub 仓库地址统一为 `Dheudb/xuloom`。

- 名称、Python 包与 CLI 统一为 `xuloom`。运行时只识别 `.xuloom` 配置，不提供旧 `.codeclaw` 别名。升级前备份并自行迁移旧配置、数据与外部技能目录；私人技能不随程序分发。
- 增加每会话独立保存的 Solo / Auto / Ultra 协作档位，默认并发 0 / 3 / 8。档位与访问权限、模型思考强度独立，复用原生子代理生命周期；子代理不开放递归委派。
- Auto/Ultra 默认单次子代理响应上限 64,000 tokens，每轮共享输出额度 1,000,000 tokens。单次仍受接口及剩余预算约束，共享表示所有子代理和响应的累计额度，不是金额上限。
- 回复支持复制、从所选回复分支；提示词支持复制，正文支持原生拖动选字与重新选择。分支保留到所选回复为止的上下文和过程记录，保留原会话、草稿，不复制正在运行的目标、命令或子代理状态。工作区文件不回滚为历史快照。
- 输入框改为“＋”菜单：文件和图片、目标、计划模式、定时唤醒、Skills、MCP 市场和模型设置。目标配置复用现有目标引擎；启用目标或计划后显示标签，模型、协作和发送控制移到右侧。
- Windows 便携包继续自带 Python，原安装可原位更新资源。内置仅包含四个公开 Skill；私人 Taiyi Skill、API Key、个人配置、历史及工作区不进入发布包。

下载 `Xuloom-v0.1.0-beta.10-windows-x64.zip`，完整解压后运行 `Xuloom.exe`；同时提供 `SHA256SUMS.txt` 校验。

本版本验证以本地确定性模型、协议故障和隐藏窗口测试为主；真实远端模型长任务、Linux/macOS 成品和操作系统级强沙箱仍未完成验收。GitHub Actions 保留手动触发，不因推送反复运行。
