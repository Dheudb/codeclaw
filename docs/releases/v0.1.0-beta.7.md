# CodeClaw v0.1.0-beta.7

统一 CLI、桌面和程序入口的引擎关闭流程，修复退出时保存或清理失败却继续关闭的问题。桌面等待真实关闭成功回执；失败保留窗口和草稿，解除占用后可重试。并发关闭共享清理任务，等待方取消不打断清理，失败保留会话写者租约，成功后释放。关闭中的引擎拒绝新任务，已关闭引擎不能直接保存并重新取得租约。

停止当前任务仍可继续或编辑提示词。子代理只清理自身命令，不释放父会话的租约和共享服务。命令终止失败可重试，其余清理仍被等待；移除两处未使用的流式工具聚合 Future，避免保存错误产生未读取的异步异常。

下载 `CodeClaw-v0.1.0-beta.7-windows-x64.zip`，完整解压后运行 `CodeClaw.exe`。本地维护仍更新同一原 EXE 的资源，构建 `20261027-221722`，保留回滚资源。
