# Xuloom v0.1.1

新增后台网页截图与视觉检查，并修复浏览器资源清理和版本升级元数据。版本为正式补丁发行，不带 beta 后缀。

## 下载与启动

下载 `Xuloom-v0.1.1-windows-x64.zip`，完整解压，运行其中的 `Xuloom-win32-x64/Xuloom.exe`。保留同目录 `resources`，不要只拷贝 EXE。包内自带 Python 与 MCP SDK；在设置中填写自己的模型连接。

## 本次变化

- 通过 `browser_tool` 的 `render` 操作，在隐藏窗口渲染工作区 HTML 或本地开发服务，截图直接交给支持图片输入的模型。桌面无需另装 Chromium；CLI 仍使用可选 Playwright 后端。
- 截图复用已有的过程缩略图、放大和历史快照。支持视口、等待时间和有尺寸上限的长页面截图；取消或超时清理拥有的隐藏窗口。
- 浏览器启动失败会清理已创建的驱动；关闭某个句柄失败仍继续清理其余资源，并暴露失败。无效截图宿主回执明确失败。
- 渲染页面的错误日志兼容安装包与较新 Electron 的事件格式，返回给模型辅助排查。
- 更新时移走旧版 Python 包元数据，失败时一起回滚，避免内部版本查询仍命中旧发行。暂存资源生成发行包时也排除过期元数据。

## 验证与边界

使用隔离配置、本地确定性模型接口、隐藏窗口和故障注入测试；没有调用用户的远端模型。详细验收与后续边界见 [本轮框架检查](https://github.com/Dheudb/xuloom/blob/v0.1.1/docs/framework-review-2026-10-31.md) 与 [后台截图说明](https://github.com/Dheudb/xuloom/blob/v0.1.1/docs/browser-capture.md)。

浏览器沿用权限审批，系统执行隔离模式下仍禁用；网页渲染不等于任意原生应用自动化。文本模型不能据此获得视觉理解。真实模型长任务、跨供应商兼容及 macOS/Linux 桌面包仍需独立验收。

发行包仅含九项公开内置 Skill，**不包含私人 Taiyi Skill、模型 Key、聊天记录或工作区文件**。`SHA256SUMS.txt` 提供下载校验，包内 `RELEASE.json` 记录源码提交与构建号。
