# Xuloom v0.1.0-beta.19

Windows x64 便携版。完整解压 ZIP 后运行 `Xuloom.exe`；本地继续更新原安装路径。

- 设置中可按模型声明文本、图片与协议支持的文档输入；请求前检查当前及历史媒体，回退模型也检查。未知能力不猜测，不自动 OCR 或换模型。
- 修复文件读取和 MCP 图片被转成字符串的问题，保留原生媒体块和文字证据，兼容接口收到实际 image_url。
- 文件工具写入前持久化原文字节与修订记录；对话文件卡片可确认撤销最近一次写入，CLI `/undo` 与程序 `undo_file` 共用同一实现。拒绝覆盖后续改动，支持重启和幂等重试。
- 配置 JSON 损坏不再静默覆盖；桌面和 CLI 的模型配置读改写复用同一 OS 锁与原子保存，避免并发丢失不同连接。
- 没有新增全局提示词、运行时依赖或另一套 Agent 调度器。

范围、验证证据和边界见 [输入与恢复加固记录](../input-and-recovery-hardening-2026-10-30.md)。撤销限宿主模式的文件工具记录，不能回滚 Shell、MCP 等任意外部副作用；旧会话没有备份的改动不能凭空恢复。macOS/Linux 成品和真实远端长任务仍需独立验收。

不包含私人 Taiyi Skill、用户配置、密钥、会话或工作文件。
