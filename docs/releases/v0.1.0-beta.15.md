# Xuloom v0.1.0-beta.15

Windows x64 便携版。下载 Release 中的 ZIP，完整解压后运行 `Xuloom.exe`。

- 支持 Markdown 中 `$…$` 行内公式、`$$…$$` 独立公式，以及同一行书写的双美元公式。
- 公式使用本地 KaTeX 与字体渲染，不需要连接公式 CDN。
- 公式旁提供“复制 LaTeX”，复制原始表达式；整条回复复制仍保留原始 Markdown。
- 不完整或不支持的公式保留原文，仍可复制；代码围栏中的美元内容保持代码，不误渲染。
- 禁止公式中的可信 HTML、外部链接和资源指令，限制宏展开；使用统一的已修补 KaTeX 依赖。

验证涵盖行内、独立、矩阵和错误公式，LaTeX 原文复制、键盘操作与复制失败重试，本地字体，以及原有代码复制、提示词复制、文本选择、会话分支和重启恢复；另回归网页链接。均使用本地测试，未调用远端模型。本次未修改 Python 执行逻辑，未重跑 Python 全量。

不包含私人 Taiyi Skill、密钥、个人接口配置、聊天记录或工作目录。模型接口由使用者自行配置。`SHA256SUMS.txt` 用于校验下载包。
