# 文件阅读与分栏调整（2026-10-30）

原右侧面板的最大宽度固定为 760，达到上限后拖动不会继续扩大；文件目录栏固定占面板的 30%，没有独立分隔条。源码与差异使用不折行文本，面板较窄时必须横向滚动，组合起来容易产生内容被锁住的感觉。

本次修改：

- 外侧面板按窗口可用空间调整，保留聊天区的最小阅读宽度，取消 760 的固定上限。
- 文件内容与目录树之间增加可拖动分隔条。两条分隔条支持键盘方向键、双击恢复默认，各自保存宽度；窗口缩小时只约束显示宽度，保留用户偏好。
- 源码和差异默认自动换行；标题栏可切换“自动换行”。关闭后保留完整长行与横向滚动。红绿差异、行号和文件原文保持原义。
- HTML 预览存在时，拖动期间暂停 iframe 接收鼠标，结束后恢复，避免其抢走拖拽事件。
- 标题显示文件名，完整路径保留在悬停提示中。

本地 Electron 文件端到端验证了实际鼠标将面板扩大到 1100、拖动内部目录栏、两项设置写入独立布局字段、长行包含完整结尾、折行时无横向裁切、关闭折行后的横向滚动，以及文件正文的原生滚轮滚动。原滚动/布局端到端验证了历史栏及右侧面板拖动、读流时滚动位置保持、原生滚动条、窄窗口和重启恢复。
