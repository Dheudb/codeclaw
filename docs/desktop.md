# 桌面 App

## 使用 Windows 便携包

下载：[Windows x64 Release](https://github.com/Dheudb/codeclaw/releases/tag/v0.1.0-beta.1)。
请选择 Assets 中的成品 ZIP，`Source code` 下载项仅包含源码。

1. 解压完整的 `CodeClaw-win32-x64` 目录。
2. 运行 `CodeClaw.exe`。
3. 点击“新建会话”即可使用自动创建的默认工作区；需要自己的文件夹时再点击“打开项目”。
4. 在“设置与模型”配置模型协议、地址、模型 ID 和 Key。
5. 输入任务。文件修改、命令和外部工具按会话权限执行。

便携包内置 Python 及 MCP 依赖。使用桌面包不需要安装 Python、Node.js、pip，
也不需要选择解释器。请保留 `resources/` 等随包文件；只复制一个 exe 不能运行。
使用本地模型时，仍需自行启动对应的模型推理服务。

源码开发方式见[开发说明](development.md)。

## 界面入口

| 入口 | 用途 |
|---|---|
| 侧边栏项目与会话 | 打开项目、新建会话、恢复项目历史 |
| 设置与模型 | 模型连接、默认工作目录、已归档会话管理 |
| Skills 面板 | 导入技能目录、刷新、选择使用、查看指令 |
| 代理面板 | 导入代理定义、查看和取消后台任务 |
| 活动面板 | 查看工具调用与任务日志 |
| 变更面板 | 自动列出会话修改的文件、行数统计和文件预览，另可查看 Git 差异 |
| MCP 市场 | 安装、配置、测试和启停外部工具 |

模型设置详见[模型配置](models.md)，能力目录规范详见[Skills 与子代理](capabilities.md)。

默认工作区在运行时按当前系统和用户解析，不包含开发者电脑的用户名或路径：

| 系统 | 默认工作区 |
|---|---|
| Windows | `%LOCALAPPDATA%\CodeClaw\workspaces\default`，未设置时使用当前用户的 `AppData\Local` |
| Linux | `$XDG_DATA_HOME/codeclaw/workspaces/default`，未设置时为 `~/.local/share/codeclaw/workspaces/default` |
| macOS | `~/Library/Application Support/CodeClaw/workspaces/default` |

目录在首次新建会话时自动创建，可在设置中独立保存新的默认目录，无需先配置模型。
顶部“新建会话”、欢迎页入口和 Ctrl+N 创建独立会话，在默认根目录下分配专属工作目录，并单独列在侧栏“独立会话”中。项目旁的加号和项目菜单中的“新建会话”才在对应项目下创建对话。修改默认目录不会移动已有项目或历史；独立会话的归档、恢复和删除同样可用。
会话保存在用户级集中存储，CLI 可在对应工作目录恢复同一会话。
上述路径逻辑适配三个系统；当前自带 Python 的发行包和成品验收仅提供 Windows 版本，Windows exe 不能在 Linux/macOS 上直接运行。

## 会话和停止

可将本地文件、图片拖到聊天窗口，点击输入框左下角回形针选择多个附件，或直接粘贴剪贴板图片。
附件以卡片显示，可移除、查看图片大图；无需输入文字也能发送。每条消息最多 10 个附件，图片最大 20 MB，其他文件最大 64 MB。
PNG/JPEG/WebP/GIF/BMP 图片会转换为图像输入发送给模型，需要供应商和所选模型支持视觉输入；不支持时接口错误会正常显示，不会把图片悄悄替换成文字。
PDF、代码和其他文件提供会话内副本路径，代理通过文件读取工具或适合该格式的本地工具读取。
附件副本与草稿统一保存在集中会话存储，原文件不会移动；原文件删除后已添加的附件仍可使用。附件跟随会话移动和复制，随会话删除清理。

停止后保留已收到的文本、工具结果和文件修改，并显示“继续执行”“编辑提示词”。
“继续执行”在同一会话内带着已有上下文发起新的请求，不要求手动输入“继续”，也不恢复已经结束的网络连接或进程。
点击最后一条用户消息的编辑图标，或在空输入框连按两次 Esc，可修改最后一条提示词；停止后也可直接点击“编辑提示词”。
编辑草稿在切换会话、重启后保留。提交后替换最后一轮消息及其过程，保留更早的对话和当前工作目录；已执行的文件修改不会撤销。
替换前的会话快照保存在集中历史的该会话资源目录中，随会话删除一并清理。

Windows 本地更新始终使用原来的 `CodeClaw.exe` 路径，不另建按功能命名的应用目录。
程序运行中只准备资源更新，退出后原位替换并保留回退文件；原有快捷方式、配置和会话继续使用。

OpenAI 兼容接口支持标准工具调用，也兼容 DeepSeek 接口原样返回的完整 DSML 工具块。
兼容调用仍经过相同的参数、工具范围和权限检查，不执行代码示例或不完整的协议块。

右侧面板左边缘可拖动调宽，也支持方向键调整、双击恢复默认宽度。
宽度保存在当前用户的桌面设置中；窗口变窄时自动限制面板宽度，为聊天区保留空间。

活动面板展示主代理和子代理的操作名称、任务或命令、状态和结果预览；展开后可查看参数和返回输出。
包含工具调用的回复上方显示执行过程和用时：运行中默认展开，完成、停止或失败后默认折叠，点击即可查看中间过程文字和工具参数/结果。没有工具调用的回复只显示用时，不显示展开箭头或空过程区。
回复和执行过程中的 HTTP/HTTPS 链接可点击，在系统默认浏览器打开；支持来源标题链接和直接显示的 URL，旧会话也生效。
用时覆盖整轮任务（包括模型请求、工具执行及等待批准）。执行过程单独保存在会话元数据中，重启后可查看；旧会话从已有消息恢复过程，有时间戳时显示估算用时，缺少时间戳时不编造时长。
支持搜索和按代理筛选，等待批准、失败和取消分别显示。重新打开会话时，从共享会话和子代理记录恢复最近的活动；引擎日志展示本次运行的日志。

输入框旁的“访问权限”提供两档：

- **请求批准**：默认模式。只读操作通常直接执行；需要审批的文件修改、命令和外部工具显示确认卡片。
- **完全访问**：本会话的主代理和子代理执行工具无需批准；等待中的工具/计划审批会继续执行，补充信息问题仍需用户回答。

权限按会话保存在集中存储的索引，重启或重新打开历史后恢复。新建/复制会话默认请求批准。
可在任务期间切换；切回请求批准会撤销先前记住的工具允许规则，后续调用重新遵循审批策略。
Agent/Plan 与访问权限分别设置；Plan 仍限制计划阶段的文件修改，完全访问时完成计划后无需额外审批即可退出计划阶段。
完全访问使用当前系统用户的权限，不会自动获取管理员权限或解除操作系统限制。

每个桌面会话拥有独立引擎进程，工作目录是打开的项目。停止操作会取消当前任务、
等待中的审批和后台子代理。恢复历史不会自动重跑上次退出时未完成的子代理。
会话按所属项目分组，每条会话只显示一次。打开的项目、当前选中的会话和输入草稿会自动记住，重启后恢复。
再次打开同一项目会切换到已有工作区；需要空白对话时点击“新建会话”。
顶部新建会话每次创建独立会话和专属目录；项目内加号仍在该项目中创建会话。

每个会话右侧的 `…` 菜单支持重命名、置顶、归档、复制为新会话和删除。
删除需在同一菜单中再次确认；正在运行的会话会明确显示“停止并删除”。
删除当前会话后，会自动选择同项目下的其他会话，再选择其他项目会话；没有可选会话时在当前项目创建空白会话。
归档保留记录，主侧边栏始终隐藏已归档内容。进入“设置与模型 → 已归档会话”，可按名称、项目或路径搜索，
点击“恢复”后记录重新出现在侧边栏；恢复不会切换当前对话，也不会重跑任务。
已归档项目在同一页面恢复；恢复项目保留各会话自身的归档状态，恢复归档项目中的单个会话会同时恢复所属项目。
旧版的显示归档开关设置不再生效。搜索、排序和批量管理仍位于侧边栏列表上方。

项目菜单中的“关闭项目”保留会话；“从列表移除项目”保留磁盘记录，重新打开项目可找回；
“删除项目会话记录”会在确认后删除此项目的全部会话，并保留项目代码和文件夹。
删除前先停止并释放相关引擎，避免引擎退出保存把已删记录写回来。
Windows 附件清理会进行有限重试；若仍被占用或无法访问，会保留会话记录和索引并提示重试，不再先删记录后留下权限错误。

CLI 和桌面端使用同一套用户级集中存储。工作目录只放项目文件和配置，不保存聊天记录。保存后可切换入口恢复会话。
回到桌面窗口或点击刷新会重新扫描 CLI 保存的历史。会话名称、归档、置顶和草稿保存在
集中存储的会话索引，CLI 覆写对话文件时会保留这些设置。
目前没有同一会话跨入口并发写入保护，请切换使用同一个会话。

## 集中存储与独立工作区

默认数据根目录由操作系统和当前用户决定：Windows 为 `%LOCALAPPDATA%/CodeClaw`，Linux 为 `${XDG_DATA_HOME:-~/.local/share}/codeclaw`，macOS 为 `~/Library/Application Support/CodeClaw`。CLI 与桌面端一致；可用绝对路径环境变量 `CODECLAW_DATA_DIR` 覆盖数据根目录。

聊天、标题、草稿、置顶、归档、执行轨迹、子代理记录和工具输出集中在数据根目录的 `history/<工作目录标识>/`；会话记忆和计划也保存到数据根目录中。项目中的 `.codeclaw` 保留 Skill、Subagent、权限及其他配置，不再新增 `sessions`、`session-index.json` 或工具输出目录。

顶部“新建会话”和 Ctrl+N 每次创建一个独立工作区，默认位于 `workspaces/default/chat-<随机标识>/`，不会复用空白会话或其他独立会话的文件。设置里的默认目录作为这些工作区的根目录。项目中的加号继续使用对应项目目录。

左右侧栏都可拖动分隔线调整宽度，重启后保留；双击分隔线恢复默认宽度，也支持方向键调整。
缩小窗口时会临时收缩侧栏，为聊天区保留空间，重新放大窗口后恢复偏好宽度。
聊天回复在底部时自动跟随输出；滚轮向上或拖动滚动条查看历史时停止跟随，回到底部或发送新消息后继续跟随。

首次打开会迁移旧版 `.codeclaw/sessions`、索引和工具输出，校验后清理已迁移的旧文件；迁移冲突保留双方记录并显示错误，不覆盖历史。旧独立会话会分配各自的工作目录，并复制聊天记录中能确认由该会话写入的现存文件，原文件保留在旧目录。未记录来源的文件仍留在旧目录，不按归属猜测迁移。标题、草稿、归档和当前选择随迁移保留。

拖动会话到项目会更新工作目录和集中存储中的关联，后续命令、Skill、MCP、Subagent 从目标项目加载。删除聊天保留工作文件；从侧边栏移除项目也不删除集中保存的历史。

## 文件预览与变更行数

文件写入、编辑和 Notebook 修改后，回复下方自动显示文件卡片；每轮按同一文件修改前后计算净新增/删除行数，
重复编辑合并为一条。超过三个文件时可展开列表。子代理的文件修改也会记录，不需要 Git 仓库。

点击卡片或右侧“变更”页中的文件，默认在可调宽度的右侧打开行级差异：新增标绿、删除标红，同时显示修改前后行号。
会话差异来自对应任务的修改前后快照，文件后来被删除也仍可审阅。切换“源码”或“预览”可查看磁盘最新内容；
回复中的文件名直接打开最新内容。Markdown 支持渲染预览，HTML/HTM 支持内嵌网页预览；源码和差异视图只显示文本。
可刷新内容，应用内再次写入同一文件时也会更新已打开的内容。

HTML 的“预览”运行在独立来源的沙箱页面，支持 CSS/SVG 动画、JavaScript 交互，以及工作区内的相对路径图片、
样式、脚本模块和 JSON 数据。点击回复或文件树中的 HTML 文件默认预览；从变更卡片打开时先显示差异，可切换“预览”。
刷新会重载网页和本地资源，页面交互状态随之重置。网页不能访问 CodeClaw 的 IPC、Node 或主界面，也不能通过预览协议读取工作区外资源、隐藏配置目录或执行写入请求。
每项预览资源最大 30 MB。预览提供静态网页资源，不会启动项目后端或编译 JSX/TypeScript；需要开发服务器的项目仍需先运行对应服务。

右侧“文件”页和审阅面板旁的工作区文件树均支持逐层展开文件夹、点击查看文件、刷新目录。
文件树跟随当前会话工作目录，隐藏 `.git` 内部目录；工作区外的目录链接不可展开。
审阅面板可切换工作区树和会话变更列表，也可收起文件树以增加阅读空间。

文件卡片及差异随历史保留。旧历史可恢复文件入口；只有能确认新建内容时才补充行数，
未保存修改前内容的旧记录显示“未记录行数”。较大文件或差异会明确提示截断；二进制及非 UTF-8 文件暂不支持文本预览。
Git 仓库会额外显示“Git 工作区差异”，检查当前工作目录内相对 HEAD 的未提交改动，包含暂存、未暂存、删除和未跟踪文件。
首次提交前的仓库也可查看新增文件。Git 差异和会话差异使用同一红绿审阅视图；普通文件夹显示无 Git 仓库提示。

## 常见问题

通用子代理生命周期、角色权限、命令会话与 MCP 超时配置见 [通用执行接口](framework.md)。后台命令在模型回复后仍运行时，输入框上方显示运行数量，并可停止全部后台任务。

- **界面打开但不能聊天**：检查模型地址、Key、模型 ID，以及本地推理服务是否启动。默认直连；需要代理时在“设置与模型”切换连接方式。Key 显示“已保存”遮罩时，留空保存会保留原值。
- **模型能聊天但不会使用工具**：检查模型和推理服务的工具调用支持，见模型兼容说明。
- **MCP 测试失败**：检查安装卡片里的前置条件、凭据和网络；本地 MCP 程序可能需要自己的运行环境。
- **内置运行时缺失**：重新解压完整的便携包，应用不会改用系统 Python。

桌面版当前提供 Windows 便携包；自动更新、签名安装器和其他平台的桌面分发尚未提供。
