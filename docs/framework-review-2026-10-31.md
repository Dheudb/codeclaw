# 框架检查与修复（2026-10-31）

本轮围绕后台渲染、取消清理、会话中的图像结果、浏览器资源生命周期与资源升级检查。沿用现有工具执行、权限、会话和媒体存档，没有增加另一套 Agent 调度状态机或全局规划请求。

## 已修复并复现验证

1. Playwright 部分启动失败会遗留驱动。故障注入验证启动异常后清理资源，重试可重新启动。
2. 原关闭流程在页面关闭异常时跳过浏览器与驱动。现在尝试清理所有已拥有的句柄，再报告首个失败；重复关闭安全。
3. 截图宿主返回非对象时可能抛出含糊的属性错误。现在返回明确的失败，不生成成功图片回执。
4. 不同 Electron 的控制台错误事件参数不同，可能漏掉页面错误。兼容两种格式，并在真实成品截图链路中验证错误标记进入工具结果。
5. 原资源升级没有退休旧版 `.dist-info`。现在先备份旧元数据，再替换资源，任何失败都通过原有回滚路径恢复；Windows 文件锁故障注入覆盖失败回滚。ZIP 暂存资源覆盖也排除过期元数据。

## 验证范围

源码与原 EXE 均使用隔离配置和本地协议模型替身，验证真实页面像素、长页底部、图像进入模型请求、缩略图/放大、历史恢复、取消清理、Cookie/Node 隔离和无效输入。九项公开 Skill 按白名单打包，私人 Skill、用户配置和历史不进入成品。

## 仍需独立验收

- 本地协议验证不能证明真实模型一定主动使用子代理或正确理解图片；遵循用户要求，未调用远端模型。
- 多小时任务、真实限流和断网后的长期运行稳定性需要持续实测，不能用单次测试数量替代。
- macOS/Linux 桌面分发与对应系统隔离仍未验证；当前桌面成品为 Windows x64。
- CLI 浏览器依赖需要额外安装；桌面免安装能力仅针对一次性网页渲染，不是任意原生应用自动化。
